🎯 Clipping Plane Functionality

// New axis-aligned plane creation functions:

+Plane - Creates camera-oriented clipping plane
+X Plane - Creates plane perpendicular to X-axis (normal: 1,0,0)
+Y Plane - Creates plane perpendicular to Y-axis (normal: 0,1,0)
+Z Plane - Creates plane perpendicular to Z-axis (normal: 0,0,1) ✨ NEW
-Planes - Deletes all clipping planes
